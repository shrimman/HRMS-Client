# HRMS Client

A modern Human Resource Management System (HRMS) frontend application built with React and TypeScript. This application provides a Frontend client for managing employee information, profiles, job postings, achievements, travel bookings, and Game Scheduling.

## Technology Stack

### Frontend Framework & Routing
- React
- React Router DOM
- React Hooks

### State Management
- Redux Toolkit
- Redux Slices

### Styling & UI
- Tailwind CSS
- ShadCN UI Components
- Lucide Icons
- cn Utility Function
- Reusable Card Component

### Type Safety
- TypeScript

### Form Handling & Validation
- React-hook-form
- Zod Validation

### API Communication
- Axios
- JWT HTTP-Only Cookie Authentication
- Environment Variables

### Component Structure & Architecture
- Component-Based Architecture
- Layout
- Outlet
- Sidebar Navigation
- Navbar
- Responsive Design

### Custom Development
- Custom Hooks
- Utility Functions
- Loaders
